# React Component Folder Organization

## UI Components Folder
- Contains basic, reusable UI elements
- Examples: Button, Input, Card, Modal, Alert
- Small, focused, and stateless components
- Used throughout the entire application

## Layout Components Folder
- Controls page structure and positioning
- Examples: Layout, Container, Grid, Sidebar
- Provides consistent spacing and arrangement
- Usually wraps other components

## Feature Components Folder
- Contains domain-specific functionality
- Examples: UserProfile, ProductCard, SearchResults
- Often combines UI and layout components
- Typically used on specific pages only
- May contain business logic
